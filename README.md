# forestMind 🌲

**FreeMind 1.0.1 互換**のモダンなマインドマップエディタです。Web ブラウザおよび **Electron デスクトップアプリ**として動作し、複数のマップを「森（Forest）」として横断的に管理・検索・リンクできるほか、思考の成長過程を音とアニメーションで再生する**思考再生（プレゼンテーション）機能**を備えています。

- React 19 + TypeScript + Vite 製（Electron による Windows デスクトップアプリ化にも対応）
- Web 版はサーバー不要で `localStorage` に自動保存、デスクトップ版はローカル `.mm` ファイルを直接読み書き可能
- 既存の FreeMind / Freeplane の `.mm` ファイルをそのまま読み書き可能（`.mm` ファイル関連付け対応）

## ✨ 主な機能

### 📝 マインドマップ編集

- ルートを中心とした左右自動バランス配置と、ベジェ曲線によるブランチ描画
- キーボード主体の高速なノード作成・編集・移動（[ショートカット一覧](#-キーボードショートカット)）
- **ノードのコピー・カット・ペースト**（`Ctrl+C` / `Ctrl+X` / `Ctrl+V`）：内部ノード複製に加え、外部の Markdown 箇条書きテキストを貼り付けて自動でツリー展開可能
- **ノードの即時複製**（`Ctrl+D`）：同じ階層の直下にサブツリーごとクローン
- **キーボード並び替え**（`Alt+↑` / `Alt+↓`）：マウスを使わず兄弟ノードの順番をクイック入れ替え
- **ドラッグ＆ドロップの視覚ガイド**：移動先ノードに「➕ 子ノードとして移動」バッジと光彩を表示し、誤操作を防止
- **ダークテーマ対応**：ツールバーの 🌙 / ☀️ ボタンで、目に優しい洗練されたダークモードへワンクリック切り替え
- **クイック色分け・アイコン・タグ付け**：`1`〜`6` キーでクイック配色（`0` でクリア）、`Alt+1`〜`9` で組み込みアイコン、`Q` / `Ctrl+K` のフローティングパレットから定型属性タグ（優先度・ステータス）を連続適用でき、`Ctrl+クリック` の複数選択にも対応（ライト／ダーク双方で高コントラスト表示）
- **ノード右クリックメニュー & ノードリンクコピー**：ノードを右クリック（または `Shift+F10`）して編集・複製・フォーカス・装飾へ素早くアクセスでき、「このノードへのリンクをコピー（`.mm#NODE_ID` / `forest://TAB_ID#NODE_ID`）」で特定ノードへの直接ジャンプも可能
- **マップ内フィルタ（`Ctrl+Shift+L`）**：クイック配色・アイコン・属性タグ（優先度・ステータス）で一致ノードと祖先パスをスポットライト強調表示（折りたたみ配下の一致件数バッジ・前/次一致ジャンプ対応）
- **フォーカスモード（`Ctrl+Shift+F`）**：選択ブランチを一時的なルートとしてズームイン（Hoist）表示し、上部パンくずナビから任意の親階層や全体表示へ戻れる集中編集モード
- **インタラクティブ・ミニマップ & 全体フィット（`Ctrl+0`）**：右下のミニマップで全体位置を把握・視点移動でき、`Ctrl+0` でマップ全体を画面に自動フィット
- **ノートポップオーバー**：ノート付きノードにホバー／クリックすると、HTML / 簡易 Markdown 整形済みのノートをポップオーバーで表示（編集・削除も可能）
- **未保存状態の可視化と保存確認**：未保存の変更があるタブには `*` を表示し、タブを閉じるときやアプリ終了時に保存確認ダイアログを表示
- **新規ノード編集のスムーズ化**：`新規ノード` を編集開始すると入力欄が自動でクリアされ、すぐに入力可能（作成直後の編集中に `Esc` を押すとノード自体を削除してキャンセル可能）
- **デスクトップ版の直接ファイル操作**：`Ctrl+S` で上書き保存・名前を付けて保存でき、開く／保存ダイアログは直前に使用したフォルダを記憶（エクスプローラーから `.mm` をダブルクリックして起動・タブ追加にも対応）
- 展開 / 折りたたみ、全展開 / 全折りたたみ
- Undo / Redo、操作成功時のクイックトースト通知
- 無限キャンバスのパン（背景ドラッグ）＆マウスホイールズーム（25%〜300%）
- マップ内のキーワード検索（一致ノードへの順送り / 逆送りジャンプ）
- **アバウト画面**：ツールバー左上の `forestMind` をクリックしてバージョン確認・実行環境情報のワンクリックコピー・ライセンス表示・開発支援（Buy Me a Coffee）や GitHub 各種リンクへアクセス

### 🌳 マルチタブ・フォレストビュー & 森林俯瞰表示 (v2.0.0)

- 複数のマップをタブで同時に開いて編集
  - **タブの並び替え**：タブをドラッグ＆ドロップして好きな順序に入れ替え（挿入ラインガイド表示・順序永続化）
  - **タブのピン止め（固定）**：タブ左アイコンをクリックして左側へピン止めし、`×` 非表示で誤閉じを防止（状態永続化）
  - **タブ右クリックメニュー**：ピン止め・閉じる・「このマップの関連を俯瞰表示」・保存済み `.mm` ファイルの「ゴミ箱へ移動」を実行可能
- **森フォルダ（ワークスペース）& 最近使ったファイル履歴**：よく使う `.mm` フォルダを「森フォルダ」として永続登録（最大12件）し、ワンクリックで一覧表示・フォルダ限定検索が可能。ツールバー「開く」横や森林ビューから「最近使ったファイル」（最大15件）にも即座にアクセスできます
- **マインドマップの安全な削除（OS のゴミ箱へ移動）**：森林ビューのカード・俯瞰表示インスペクタ・タブ右クリックメニューから保存済み `.mm` ファイルを OS のゴミ箱へ安全に移動可能（未保存変更や他マップからのバックリンク件数を警告表示し、開いているタブ・履歴・森フォルダ一覧も自動同期）
- **ブランチの株分け & 合流（リファクタリング）**：右クリックメニューまたはフォーカスモードから、大きくなった枝を別 `.mm` ファイル／別タブへ独立（元ノードは相対パスまたは `forest://` リンクへ置換・格納選択可）でき、逆に他タブや別 `.mm` ファイルを現在ノードの配下へ合流（ID自動再採番・内部リンク維持）できます
- **ツリー間ポータル参照（ゴーストノード）**：`.mm`（`#NODE_ID` 指定可）や `forest://` リンクを持つノードのポータルアイコンまたは右クリックメニューから、リンク先ツリーをキャンバス上に点線枠・参照専用のゴーストノードとしてインライン展開プレビューできます（「別タブで開く」やノードクリックで元マップへジャンプ可能）
- **森林ビュー（カード表示 / 俯瞰表示）** で全マップを一覧・俯瞰
  - **カード表示**：各マップのノード数・最大深さ・主要トピックのプレビュー、および全タブ＋登録森フォルダ横断のキーワード検索
  - **俯瞰表示**（ヘッダー切替または `Ctrl+Shift+G`）：ノード数・深さ・リンク数に応じた **6種類の樹形アイコン（若芽・若木・低木/茂み・のっぽの針葉樹・大樹・巨樹）**、更新経過日数（**今週 / 今月 / 今年 / それ以上＝もみじ色の深紅**、XML 更新日時またはファイル更新日時基準）に応じた **季節カラー**、2次元大森林レイアウト＋尾根の等高線、マップ間の `.mm` / `forest://` 発リンク・バックリンク曲線、フルスクリーン（`F` / `Esc`）、滑らかなパン＆カーソル基準ホイールズーム、**「森全体 / 関連のみ」** スコープ切替（個別マップのツールバー「関連俯瞰」またはタブメニューから直行可）、ツールバー上の **森フォルダ解除チップ（`×`）**、右側の詳細インスペクタを提供

### ▶️ 思考再生（プレゼンテーション）

マインドマップが「育っていく」様子をノード単位でアニメーション再生します。`F5` で開始 / 終了。

- **3つの再生順序**
  - **トピック順**：深さ優先。主題ごとに掘り下げて展開
  - **階層順**：幅優先。全体の骨格から順に肉付け
  - **時系列順**：ノードの作成日時（`CREATED`）順。思考の歴史を再現
- **シネマ全画面モード（`F`）**：ツールバーやタブバーを滑らかにフェードアウトさせ、余計なUIのない没入感ある発表ビューに切り替え
- **スポットライト演出（`L`）**：思考の「幹から現在地までの経路」を美しく照らし出し、他の枝を落ち着いたトーンにディマー表示
- **スマート・カメラ追従（`C`）**：新しく生まれたノードとその親ノードを自然に収めるスムーズな自動フレーミング
- **再生速度**：0.5秒 / 1秒 / 2秒 / 3.5秒 / 5秒（1ステップあたり）
- **シークバー**による任意位置へのジャンプ
- **バブルポップ効果音（`M`）**（外部音源なし・Web Audio API で合成）
  - ノードの深さに応じて**ペンタトニックスケール（ド・レ・ミ・ソ・ラ…）で音程が上昇**
  - 幹（ルート）は低く温かい音、枝葉に進むほど高く軽やかな「プチッ」という音に変化

### 🔍 ローカルフォルダ横断検索

PC 上のフォルダを指定し、配下の `.mm` ファイルを一括検索します。

- サブフォルダを含めた再帰スキャン（デスクトップ版はネイティブのフォルダ選択ダイアログ、Web 版は File System Access API／フォルダ選択にフォールバック）
- キーワード検索（大文字小文字無視、数値文字参照の自動デコード）
- 階層パス（パンくず：`大項目 > 中項目 > 小項目`）による文脈表示
- 更新日（From〜To）およびアイコンによる絞り込み
- 結果のソート表示、行ダブルクリックで該当マップを開いて対象ノードへ直接ジャンプ
- 検索結果の CSV エクスポート（Excel 対応 UTF-8 BOM 付き）

### 💾 インポート / エクスポート

| 形式 | 読み込み | 書き出し | 備考 |
| --- | :---: | :---: | --- |
| FreeMind (`.mm`) | ✅ | ✅ | ノード階層・色・スタイル・フォント・アイコン・リンク・ノート・属性・クラウド・矢印リンクをラウンドトリップ |
| Markdown (`.md`) | ✅ | ✅ | 見出し（`#`）と箇条書き（`-` / `*` / `+`）のインデントから階層を構築 |
| SVG (`.svg`) | — | ✅ | 現在のマインドマップをベクター画像として書き出し |
| PNG (`.png`) | — | ✅ | 現在のマインドマップを高解像度ラスター画像として書き出し |

> [!NOTE]
> `.mm` の書き出しでは、本家 FreeMind 1.0.1 と同じく非 ASCII 文字を 16 進数値文字参照（`&#xXXXX;`）で出力します。そのため FreeMind / Freeplane で開いても文字化けしません。

## 🚀 セットアップ

### 必要環境

- Node.js 18 以上（推奨: 20 LTS 以降）
- モダンブラウザ（Chrome / Edge 推奨。フォルダ横断検索は File System Access API 対応ブラウザで最も快適に動作します）

### インストールと起動

```bash
# 依存パッケージのインストール（初回のみ）
npm install

# 開発サーバー起動
npm run dev
```

> [!TIP]
> Windows の PowerShell で「スクリプトの実行が無効」というエラーが出る場合は、`npm.cmd run dev` のように `npm.cmd` を使って実行してください。

### その他のコマンド

| コマンド | 内容 |
| --- | --- |
| `npm test` | ユニットテスト（Vitest）を実行 |
| `npm run build` | 型チェック＋プロダクションビルド（`dist/` に出力） |
| `npm run preview` | ビルド結果をローカルでプレビュー |
| `npm run lint` | ESLint による静的解析（React Hooks の依存配列チェックを含む） |
| `npm run electron:dev` | Electron デスクトップアプリを開発モードで起動 |
| `npm run electron:start` | ビルドして Electron デスクトップアプリを起動 |
| `npm run electron:build` | Windows 向け NSIS インストーラー（`.mm` 関連付け対応）とポータブル版を `release/` に生成 |
