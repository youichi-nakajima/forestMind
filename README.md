# forestMind 🌲

FreeMind（`.mm` 形式）との高忠実度な互換性を持つ、モダンで高速なマインドマップエディタ＆ビューアです。

## 主な機能

- **FreeMind (.mm) 完全互換**
  - XML形式の `.mm` ファイルの読み込み（インポート）および書き出し（エクスポート）。
  - ノード階層、色、スタイル（Fork/Bubble）、フォント、アイコン、リンク、詳細ノート、属性（Key-Value）の完全ラウンドトリップ対応。
- **直感的なキーボード主体の操作**
  - `Tab` / `Insert`: 子ノードの作成
  - `Enter`: 兄弟ノードの作成
  - `F2` / ダブルクリック: インラインテキスト編集
  - `Space`: ノードの展開 / 折りたたみトグル
  - `Delete` / `Backspace`: ノードの削除
  - `Ctrl + Z` / `Ctrl + Y`: Undo / Redo
- **ビジュアル・レンダリング**
  - FreeMind特有のルートを中心とする左右自動バランス配置。
  - 美しいベジェ曲線によるブランチ接続線。
  - 無限キャンバスのパン（ドラッグ移動）＆ホイールズーム。
  - 右側のプロパティパネルによる文字色・背景色・フォント・属性・アイコン編集。

## 開発・起動方法

```bash
# 開発サーバー起動
npm run dev

# テスト実行
npm test

# プロダクションビルド
npm run build
```
