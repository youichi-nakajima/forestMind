# forestMind 🌲

**FreeMind 1.0.1 互換**のモダンなマインドマップエディタです。ブラウザだけで動作し、複数のマップを「森（Forest）」として横断的に管理・検索できるほか、思考の成長過程を音とアニメーションで再生する**思考再生（プレゼンテーション）機能**を備えています。

- React 19 + TypeScript + Vite 製のシングルページアプリケーション
- サーバー不要。データはブラウザの `localStorage` に自動保存
- 既存の FreeMind / Freeplane の `.mm` ファイルをそのまま読み書き可能

---

## ✨ 主な機能

### 📝 マインドマップ編集

- ルートを中心とした左右自動バランス配置と、ベジェ曲線によるブランチ描画
- キーボード主体の高速なノード作成・編集・移動（[ショートカット一覧](#️-キーボードショートカット)）
- ドラッグ＆ドロップによるノードの付け替え・並び替え
- 展開 / 折りたたみ、全展開 / 全折りたたみ
- Undo / Redo
- 無限キャンバスのパン（背景ドラッグ）＆マウスホイールズーム（25%〜300%）
- マップ内のキーワード検索（一致ノードへの順送り / 逆送りジャンプ）

### 🎨 ノードプロパティパネル

選択ノードの詳細を右側のパネルで編集できます。

| 項目 | 内容 |
| --- | --- |
| テキスト | ノード本文 |
| ノードスタイル | 文字色・背景色・フォントサイズ・太字 / 斜体 |
| リンク | URL・ファイルパス、または `forest://<タブID>` によるマップ間リンク |
| 詳細ノート | ノードに紐づく補足メモ |
| クラウド | ノードを囲む雲形の枠 |
| 矢印リンク | 任意のノード間を結ぶ関連線 |
| アイコン | ✅ ❌ 🚩 ⭐ 💡 🚀 ✏️ 🌲 📁 ❓ 🔖 📎 などの FreeMind 組み込みアイコン |
| 属性 | Key-Value 形式の任意属性 |

### 🌳 マルチタブ & フォレストビュー

- 複数のマップをタブで同時に開いて編集
- **フォレストビュー**で全マップを一覧表示
  - 各マップのノード数・最大深さ・主要トピックのプレビュー
  - `forest://` リンクによるマップ間のつながりの可視化
  - 全マップを横断するキーワード検索と、該当ノードへのジャンプ

### ▶️ 思考再生（プレゼンテーション）

マインドマップが「育っていく」様子をノード単位でアニメーション再生します。`F5` で開始 / 終了。

- **3つの再生順序**
  - **トピック順**：深さ優先。主題ごとに掘り下げて展開
  - **階層順**：幅優先。全体の骨格から順に肉付け
  - **時系列順**：ノードの作成日時（`CREATED`）順。思考の歴史を再現
- **再生速度**：0.5秒 / 1秒 / 2秒 / 3.5秒 / 5秒（1ステップあたり）
- **シークバー**による任意位置へのジャンプ、自動センタリング
- **バブルポップ効果音**（外部音源なし・Web Audio API で合成）
  - ノードの深さに応じて**ペンタトニックスケール（ド・レ・ミ・ソ・ラ…）で音程が上昇**
  - 幹（ルート）は低く温かい音、枝葉に進むほど高く軽やかな「プチッ」という音に変化

### 🔍 FreeMindSearcher（ローカルフォルダ横断検索）

PC 上のフォルダを指定し、配下の `.mm` ファイルを一括検索します。

- サブフォルダを含めた再帰スキャン（File System Access API。非対応ブラウザではフォルダ選択にフォールバック）
- キーワード検索（大文字小文字無視、数値文字参照の自動デコード）
- 階層パス（パンくず：`大項目 > 中項目 > 小項目`）による文脈表示
- 更新日（From〜To）およびアイコンによる絞り込み
- 結果のソート表示、行ダブルクリックで該当マップを開いて対象ノードへ直接ジャンプ
- 検索結果の CSV エクスポート（Excel 対応 UTF-8 BOM 付き）

### 💾 インポート / エクスポート

| 形式 | 読み込み | 書き出し | 備考 |
| --- | :---: | :---: | --- |
| FreeMind (`.mm`) | ✅ | ✅ | ノード階層・色・スタイル・フォント・アイコン・リンク・ノート・属性・クラウド・矢印リンクをラウンドトリップ |
| Markdown (`.md`) | ✅ | ✅ | 見出し（`#`）と箇条書き（`-` / `*` / `+`）のインデントから階層を構築 |

> [!NOTE]
> `.mm` の書き出しでは、本家 FreeMind 1.0.1 と同じく非 ASCII 文字を 16 進数値文字参照（`&#xXXXX;`）で出力します。そのため FreeMind / Freeplane で開いても文字化けしません。

## ⌨️ キーボードショートカット

アプリ内のヘルプ（ツールバーの ⌨️ ボタン）からも確認できます。

### ノード作成・編集

| キー | 操作 |
| --- | --- |
| `Tab` / `Insert` | 子ノードを追加 |
| `Enter` | 兄弟ノードを追加 |
| `F2` / ダブルクリック | インラインテキスト編集 |
| `Delete` / `Backspace` | 選択ノードを削除 |
| ドラッグ＆ドロップ | ノードを別の親へ移動・並び替え |

### ナビゲーション & 表示

| キー | 操作 |
| --- | --- |
| `↑` / `↓` | 兄弟ノード間を移動 |
| `→` / `←` | 子ノード / 親ノードへ移動（ブランチの左右に応じて切り替え） |
| `Space` | 展開 / 折りたたみ |
| 背景ドラッグ | キャンバスを移動 |
| マウスホイール | 拡大 / 縮小 |

### 履歴 & 検索

| キー | 操作 |
| --- | --- |
| `Ctrl` + `Z` / `Ctrl` + `Y` | 元に戻す / やり直し |
| `Ctrl` + `F` | マップ内検索バーにフォーカス |
| `Enter` / `Shift` + `Enter`（検索中） | 次 / 前の一致ノードへジャンプ |

### 思考再生

| キー | 操作 |
| --- | --- |
| `F5` | 再生モードの開始 / 終了 |
| `Space` | 自動再生 / 一時停止 |
| `→` / `↓` | 次のステップへ |
| `←` / `↑` | 前のステップへ |
| `Home` | 最初のステップへ戻る |
| `Esc` | 再生モードを終了 |

## 🚀 セットアップ

### 必要環境

- Node.js 18 以上（推奨: 20 LTS 以降）
- モダンブラウザ（Chrome / Edge 推奨。フォルダ横断検索は File System Access API 対応ブラウザで最も快適に動作します）

### インストールと起動

```bash
# 依存パッケージのインストール（初回のみ）
npm install

# 開発サーバー起動
npm run dev
```

> [!TIP]
> Windows の PowerShell で「スクリプトの実行が無効」というエラーが出る場合は、`npm.cmd run dev` のように `npm.cmd` を使って実行してください。

### その他のコマンド

| コマンド | 内容 |
| --- | --- |
| `npm test` | ユニットテスト（Vitest）を実行 |
| `npm run build` | 型チェック＋プロダクションビルド（`dist/` に出力） |
| `npm run preview` | ビルド結果をローカルでプレビュー |
| `npm run lint` | ESLint による静的解析（React Hooks の依存配列チェックを含む） |

## 📁 ディレクトリ構成

```text
src/
├── App.tsx                     # アプリ全体のレイアウトと状態の結線
├── main.tsx                    # エントリポイント
├── index.css                   # グローバルスタイル
├── components/
│   ├── MindMapCanvas.tsx       # マップ描画・キーボード / マウス操作
│   ├── Toolbar.tsx             # 上部ツールバー（編集用 / フォレストビュー用）
│   ├── TabBar.tsx              # マルチタブ
│   ├── NodePropertiesPanel.tsx # ノードプロパティ編集パネル
│   ├── ForestOverview.tsx      # フォレストビュー（全マップ一覧・横断検索）
│   ├── PresentationControls.tsx# 思考再生のプレイヤー UI
│   ├── FreeMindSearcherModal.tsx # ローカルフォルダ横断検索
│   └── HelpModal.tsx           # ショートカットガイド
├── hooks/
│   ├── useMindMap.ts           # タブ・ツリー編集・履歴・検索・入出力
│   └── usePresentationPlayback.ts # 思考再生の状態管理
├── parser/
│   ├── freemindParser.ts       # .mm (XML) → 内部モデル
│   └── freemindSerializer.ts   # 内部モデル → .mm (XML)
├── services/
│   └── freeMindSearchEngine.ts # FreeMindSearcher の検索エンジン
├── utils/
│   ├── layout.ts               # 左右バランス配置・エッジ / クラウド計算
│   ├── presentationSequence.ts # 再生順序（トピック / 階層 / 時系列）の生成
│   └── audio.ts                # Web Audio API による効果音合成
├── types/                      # FreeMind・プレゼンテーション・検索の型定義
└── data/
    └── defaultMap.ts           # 初期サンプルマップ
```

各ディレクトリの `__tests__/` にユニットテストがあります。
