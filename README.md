# forestMind 🌲

FreeMind（`.mm` 形式）との高忠実度な互換性を持つ、モダンで高速なマインドマップエディタ＆ビューアです。

## 主な機能

- **FreeMind (.mm) 完全互換**
  - XML形式の `.mm` ファイルの読み込み（インポート）および書き出し（エクスポート）。
  - ノード階層、色、スタイル（Fork/Bubble）、フォント、アイコン、リンク、詳細ノート、属性（Key-Value）の完全ラウンドトリップ対応。
  - FreeMind 1.0.1 準拠の 16進数数値文字参照（`&#xXXXX;`）による文字化け防止。
- **FreeMindSearcher 統合（ローカルフォルダ横断検索）**
  - PC上の指定フォルダ配下にある大量の `.mm` ファイルをサブフォルダ再帰で一括スキャン。
  - キーワード検索（大文字小文字無視・日本語実体参照自動デコード）。
  - 階層パス（パンくずリスト: `大項目 > 中項目 > 小項目`）の文脈表示。
  - 更新日時（From 〜 To）フィルターおよびアイコン絞り込み。
  - 検索結果の一覧ソート表示、行ダブルクリックで該当マップを開いて対象ノードへ直接ジャンプ。
  - 検索結果の CSV エクスポート（Excel対応 UTF-8 BOM付き）。
- **直感的なキーボード主体の操作**
  - `Tab` / `Insert`: 子ノードの作成
  - `Enter`: 兄弟ノードの作成
  - `F2` / ダブルクリック: インラインテキスト編集
  - `Space`: ノードの展開 / 折りたたみトグル
  - `Delete` / `Backspace`: ノードの削除
  - `Ctrl + Z` / `Ctrl + Y`: Undo / Redo
- **ビジュアル・レンダリング**
  - FreeMind特有のルートを中心とする左右自動バランス配置。
  - 美しいベジェ曲線によるブランチ接続線。
  - 無限キャンバスのパン（ドラッグ移動）＆ホイールズーム。
  - 右側のプロパティパネルによる文字色・背景色・フォント・属性・アイコン編集。

## 開発・起動方法

```bash
# 開発サーバー起動
npm run dev

# テスト実行
npm test

# プロダクションビルド
npm run build
```
